⚙️ Configuração do Google Sheets

💡 Pode colar a URL completa! Ex: https://docs.google.com/spreadsheets/d/SEU_ID_AQUI/edit

📋 Como configurar:

  1. Crie a planilha no Google Sheets com as colunas: Nome, URL, Categoria, Extra1, Extra2
  2. Torne a planilha PÚBLICA:
    • Clique em "Compartilhar" (canto superior direito)
    • Em "Acesso geral", selecione "Qualquer pessoa com o link"
    • Permissão: "Leitor"
    • Clique em "Concluído"
  3. Obtenha o ID da planilha:
    Opção 1 (mais fácil): Cole a URL completa da planilha no campo acima
    Opção 2: Copie apenas o ID da URL entre /d/ e /edit
    https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit
  4. Configure a API Key:
    • Acesse Google Cloud Console
    • Crie um novo projeto ou selecione existente
    • Vá em "APIs e Serviços" → "Biblioteca"
    • Procure e ative "Google Sheets API"
    • Vá em "Credenciais" → "Criar credenciais" → "Chave de API"
    • IMPORTANTE: Restrinja a API Key para usar apenas "Google Sheets API"
⚠️ Problemas comuns:
• Erro 403: API Key inválida ou Google Sheets API não ativada
• Erro 404: Planilha não está pública ou ID incorreto
• Erro 400: Formato do ID está errado
