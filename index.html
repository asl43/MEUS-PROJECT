⚙️ Configuração do Google Sheets

📋 Como configurar:

  1. Crie uma planilha no Google Sheets com as colunas: Nome, URL, Categoria
  2. Acesse Google Cloud Console
  3. Crie um projeto e ative a API do Google Sheets
  4. Gere uma API Key em "Credenciais"
  5. Torne sua planilha pública ou compartilhe com "Qualquer pessoa com o link"
  6. Copie o ID da planilha da URL (parte entre /d/ e /edit)
