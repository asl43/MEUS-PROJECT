⚙️ Configuração do Google Apps Script

💡 Cole a URL completa da sua Web App implantada

📋 Instruções de Configuração (Apps Script):

  1. Certifique-se de que o **código Apps Script mais recente** (com `doGet` e `doPost` para CRUD) esteja colado no seu projeto.
  2. Vá em **Extensões → Apps Script** e execute a função `inicializarPlanilha()` uma vez.
  3. **Reimplante a Web App:** Clique em **Implantar → Gerenciar implantações → Editar** → **Nova versão** → **Implantar**.
  4. Cole a URL acima e use o botão **"Carregar Sites"**.
**Dica:** Use **Ctrl/Cmd + Clique** ou **Clique Direito** em um card para **EDITAR/EXCLUIR** o site.
